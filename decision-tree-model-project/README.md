# Predicting Employee Productivity Using Tree-Based Models

## Objective
Develop machine learning models to predict employee productivity using
tree-based algorithms.

## Dataset
A garment industry productivity dataset containing employee-related and
operational features that influence productivity outcomes.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Methodology
- Performed data cleaning and exploratory data analysis (EDA)
- Analyzed productivity patterns across different variables
- Built Decision Tree and Random Forest models
- Tuned model parameters to improve predictive performance
- Evaluated and compared model results

## Results
Tree-based models effectively captured non-linear relationships in the data
and demonstrated strong performance in predicting employee productivity,
highlighting their usefulness in operational and business analytics.

## Notes
This project was completed as part of a guided data science project
focusing on applied machine learning.
