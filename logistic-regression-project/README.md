# Classifying Heart Disease Using Logistic Regression

## Objective
Implement a logistic regression model to classify the presence of heart disease
based on patient medical attributes.

## Dataset
The Heart Disease dataset containing 303 patient records with 14 clinical features,
including age, chest pain type, cholesterol level, resting blood pressure, and ECG results.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Methodology
- Explored and understood the structure of the dataset
- Performed data cleaning and preprocessing
- Conducted exploratory data analysis (EDA)
- Built a logistic regression classification model
- Evaluated model performance using classification metrics

## Results
The logistic regression model was able to identify patterns associated with
heart disease presence, demonstrating the application of statistical
classification techniques on real-world medical data.
