# Customer Segmentation Using Unsupervised Machine Learning

## Objective
Apply unsupervised machine learning techniques to segment data into meaningful
groups based on feature similarity.

## Dataset
An unlabeled dataset suitable for clustering and pattern discovery.
Exploratory analysis was conducted to understand feature distributions.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Methodology
- Cleaned and prepared the dataset
- Conducted exploratory data analysis (EDA)
- Applied K-Means clustering
- Analyzed cluster characteristics
- Visualized cluster assignments to interpret patterns

## Results
The clustering approach successfully identified distinct groups within the data,
demonstrating the use of unsupervised learning for segmentation and pattern discovery.

## Notes
This project was completed as a guided project focusing on unsupervised
machine learning techniques.
